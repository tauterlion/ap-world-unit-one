# V1 Game Flow

1. Topic selection screen shows 1.1–1.6, all unlocked.
2. User selects a topic.
3. Brief game-show intro.
4. Five category names reveal one-by-one.
5. User selects a $100–$500 tile.
6. Full-screen question view appears.
7. User thinks/says answer aloud.
8. User presses Reveal Answer.
9. Show answer + short explanation.
10. User self-grades: Correct or Incorrect.
11. Correct adds value; Incorrect adds nothing.
12. Return to board; tile stays visible but marked completed.
13. Repeat until all 25 are complete.
14. Results screen shows score, accuracy, category performance, and missed questions.
15. User can review missed questions, replay, or return to topics.
