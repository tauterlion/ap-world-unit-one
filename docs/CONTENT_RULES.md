# Content Rules

- AMSCO is the source of truth for V1 trivia.
- Only Topics 1.1–1.6.
- 5 categories × 5 questions per topic = 25 questions per board.
- $100: basic recall.
- $200: recall with context/distinction.
- $300: understanding relationships/significance.
- $400: historical reasoning and occasional stimuli.
- $500: strongest AP-style reasoning.
- Higher values should not simply mean obscure trivia.
- Mix recurring categories with topic-specific categories.
- Every revealed answer gets a short explanation.
- Prefer short/paraphrased textual stimuli over long copied passages.
- Verify every answer and explanation against the source.
